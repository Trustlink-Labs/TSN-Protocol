Pay a TIN

Resolve the recipient route, prepare the canonical TSN authorization, request the wallet signature, then submit the signed intent through the SDK.

VIEW SDK CODE · resolve + authorize + submit
const route = await resolveTinRoute({ tin, rpcUrl });
const authorization = createPaymentAuthorization({
  receiverIdentity: `tin:${tin}`,
  recipientRouteCommitment: route.tcapRelationshipCommitment,
  recipientRouteVersion: route.tcapRouteVersion,
  ...paymentFields,
});
await submitPaymentAuthorizationToMempool({ ...authorization, ...paymentFields });
